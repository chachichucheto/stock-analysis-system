## 1. 測るもの(CONCEPT §1.2)

| 指標 | 定義 | 単位 |
|---|---|---|
| 的中率(銘柄) | 本命に挙げた (シナリオ, 銘柄) のうち「動いた」割合 | 日々の確認用 |
| 的中率(シナリオ) | 本命を1つ以上出したシナリオのうち、本命が1銘柄でも「動いた」割合 | **合否の判定用** |
| 偶然の的中率 | 同じ期間に、全銘柄(流動性の下限以上)の中で「動いた」銘柄の割合 | 比較の基準 |
| 1段目だけの的中率 | 同じシナリオの1段目の候補だけを挙げた場合の的中率 | 2段目の連想の価値の確認 |
| 捕捉率 | S・A級のイベントの後に「動いた」関連銘柄(月次の振り返りで事後に判定)のうち、事前に候補(順位を問わない)に挙げていた割合 | 見逃しの確認 |
| 先行性 | 本命に挙げた日が、「動き出した日」より前だった割合と、その日数 | ― |

## 2. 定義と閾値

| 項目 | 値 |
|---|---|
| 「動いた」 | 本命に挙げた日から、想定期間内(最長20営業日)に、起点からの TOPIX 超過が +10% 以上。シナリオが強化されても期間は延ばさない |
| 起点 | 本命に初めて挙げた日の終値(レポートは引け後に出すので、その日の値動きは既に知っている) |
| 「動き出した日」 | 起点からの TOPIX 超過が初めて +5% を超えた日 |
| TOPIX の代わり | 1306(TOPIX 連動 ETF) |
| 重複の扱い | (シナリオ, 銘柄) の組で最初に本命になった日だけを1件と数える |
| 独立したシナリオ | 同じイベントから派生したシナリオは1件と数える |
| 足切り | 注目度が過去90日のイベントの上位5%、または伸びが上位5%、または強い種類の開示。1日最大3件 |
| 1段目の「反応した」 | 当日の TOPIX 超過が、普段の値動き(20日の標準偏差)の2倍以上 |
| 注目度が「高い」 | 媒体数が過去90日の上位20% |
| 流動性の下限 | 20日平均の売買代金 1億円(**要決定**) |
| ★ | 自信度の下限 0.05 / 0.10 / 0.20 で ★2〜★4(**サンプル出力を見て決定**) |

## 3. 判定(CONCEPT §11)

| 段階 | 基準 | 時期 |
|---|---|---|
| L1 運用が回る | 3か月のうち、実行した日が営業日の80%以上、かつ所要時間の中央値が30分以下 | 運用開始から3か月 |
| L2 探す能力がある | 次の3つをすべて満たす:①シナリオ単位の的中率が偶然の的中率を上回る(95%の信頼区間の下限が偶然の的中率を超える)②シナリオ単位の的中率が1段目だけの的中率以上 ③先行性が50%以上 | 独立したシナリオが60件たまった時点 |
| 保留 | L2 の①の信頼区間が偶然の的中率をまたぐ場合 | ― |

- 月次の振り返りでは合否を判定しない。
- 上記以外の切り口(テーマ別、時間の型別など)の結果は「探索的」と明記する。
