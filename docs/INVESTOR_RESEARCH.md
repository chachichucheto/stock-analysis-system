### 1.2 かぶ1000 — ネットネット/資産バリュー

| 追加の条件 | PBR1倍以下、低PER。PMV(事業家的市場価値)とカタリストの知識を使う | ○ |

### 1.4 たーちゃん — バリュー3種、特にシクリカル

| 項目 | 内容 | 信頼度 |
|---|---|---|
| 実績 | 50万円から70〜80億円。現役の麻酔科医 | ◎ |
| 3種類 | 資産バリュー、収益バリュー、**シクリカルバリュー**。利益への寄与は資産10%・収益10%・シクリカル80%(本人の整理とする記事) | ○ |
| 資産バリュー | PBR0.5倍以下、自己資本比率60%以上が例 | △ |
| シクリカルバリュー | 景気の谷にいる銘柄を買う。「収益バリュー級の成長余地を、資産バリュー級の安さで買う」 | ◎ |
| 谷の見つけ方 | 過去10年の業績を見て赤字と黒字を繰り返す企業を選び、同業5社ほどの売上推移を確認。業界全体が赤字、またはピークから株価が1/3〜1/4 | ○ |
| 買う条件 | 「2年連続赤字」くらいがベスト。ただし**生き残れる**と判断できること | ○ |

| 売り | **PERの売却水準をあらかじめ決めておく**。業務スーパーは時価総額約80億円で買い約240億円で売った(3倍) | ○ |
| 時間軸・考え方 | 長期。業績の悪い株を買って回復を待つ逆張り | ◎ |

**要点**:「みんなが嫌う+潰れない+資産で下値が支えられる」を重ねる。景気循環の見立てが鍵。

### 1.5 BNF(小手川隆) — 乖離率の逆張りから順張りへ

| 項目 | 内容 | 信頼度 |
|---|---|---|
| 実績 | 160万円から160〜200億円 | ◎ |
| 初期の手法 | **25日移動平均からの下方乖離**で逆張り。業種で目安が違う(ハイテク20%以上、証券・銀行15%以上、薬品・食品10〜15%以上)。乖離が0%に戻ったら利確 | ○ |
| 後期の手法 | 資産が10億円を超えた2004年頃から順張りへ切り替え、とする記事 | △ |
| 時間軸 | スイング。保有は数日〜1週間程度 | ◎ |
| 銘柄数 | 600〜700銘柄を常時監視し、30〜70銘柄を保有 | △ |
| 損切り | 機械的。買ったあとさらに乖離が広がるなど想定と違う動きなら即手放す。株価の5〜10%下落を目安とする記事 | △ |
| 資金管理 | 1日の損失を総資金の2%以内、とする記事 | △ |
| 付随 | 地合いが良い時と悪い時の両方の過去データを見て、今に当てはめる | △ |
| 後年 | 株式から不動産へ(資金量の壁) | ○ |

**要点**:数式化できる逆張り。ただし後年は裁量と順張りに移っており、「乖離率だけで勝った」わけではない。

### 1.6 cis — 順張りのトレンドフォロー

| 項目 | 内容 | 信頼度 |
|---|---|---|
| 実績 | 300万円から230億円、さらに410億円という記事もある | ○ |
| 核心 | 上がっている株を買い、下がっている株は買わない。「上がり続けるものは上がり、下がり続けるものは下がる」 | ◎ |
| 見るもの | 気配値と歩み値(板)、出来高、値動き、成行買いの回数と枚数 | ◎ |
| 時間軸 | 数秒〜48時間。のちに長期も併用 | ○ |
| 売り | 「下がると思ったらすぐ売る」。買値は関係ない | ◎ |
| 資金管理 | 確信したら全力。損切り後にまた上がれば買い直す。**同じ銘柄で3回外したら手を引く** | ○ |

**要点**:需給の読みが優位性で、再現に執行の速さと裁量が要る。**個人が機械的に再現するのは難しい。**

### 1.7 テスタ — 超短期・材料株の板読み

| 項目 | 内容 | 信頼度 |
|---|---|---|
| 実績 | 300万円から70〜100億円。1億円超の損失から復活した経験あり | ◎ |
| 銘柄選び | 前日に大きなニュースや事件があった銘柄。時価総額200億円以下の中小型(板読みが効く) | ○ |
| 見るもの | 出来高が急増し板が厚く、値動きが軽い、盛り上がったテーマ株。日経平均先物 | ○ |

### 2.3 正直な注意

- ここに挙げたのは**勝った人だけ**である。同じ手法で負けて消えた人は見えない(生存者バイアス)。「共通点」は勝因とは限らず、単に小型株の方が値幅が大きく、資産が増えやすいだけの可能性もある。
- 数百億円の資産は、**小型株・集中・長い期間・時代の追い風**の結果でもある。個人の資金で同じ値動きが取れる流動性があるかは別問題。
- よって「勝てる手法」と断定しない。**検証して残った手法だけ使う**、が本書の立場である。

## 3. 提案:勝てる投資家の手法で銘柄を選ぶ方法

### 3.1 設計の考え方

1. **機械化できる手法だけを核にする**(再現できない裁量の部分は無理に真似しない)。
   - 採用:かぶ1000(ネットネット指数)、たーちゃん(資産バリュー・シクリカルの数値条件)、BNF(乖離率)、片山(開示を LLM が読む)、出来高(共通 C6)。
   - 不採用(再現困難):cis・テスタの板読み。
2. **「複数の型が同時に当てはまる銘柄」を優先する**(合議)。どの投資家も、単独の指標ではなく**重なり**(割安×きっかけ×需給)で買っている。
3. **損失の限定(C4)は銘柄選択と切り離して先に決める**。

### 3.2 4つの型のスクリーン(Python で毎日計算)

| 型 | 元の投資家 | 条件(初期値。検証で変える) | 狙い |
|---|---|---|---|
| **A 資産バリュー** | かぶ1000、たーちゃん | ネットネット指数<1(または PBR<0.5 かつ 自己資本比率≥60%)。時価総額30〜500億円 | 下値が資産で支えられる |
| **B シクリカル底** | たーちゃん | 過去10年の業績が赤字・黒字を繰り返す/直近が赤字/株価が高値から-67%以上/自己資本比率で生存性を確認(有利子負債≦現預金など) | 回復の非対称性 |
| **C 成長の初動** | 片山、ぱりてきさす | 時価総額<300億円/直近2四半期で営業利益の前年比が加速/PER が成長に対して低い/出来高が20日平均の2倍以上になった日がある | 変化の初期 |
| **D 売られすぎ反発** | BNF | 25日線から業種別閾値以上の下方乖離/**A・B・C のいずれかを満たす銘柄だけ**に限定(割安の裏付けがない逆張りはしない) | 短期のタイミング |

D は単独では使わない。BNF氏の逆張りは「良い銘柄が売られすぎた時」と捉え、A〜C の**入口のタイミング指標**にする。

### 3.3 合議スコア(重なりで順位付け)

```
スコア = 型の一致数(A,B,C,D)
       + カタリストの予兆(LLM が開示から判定):還元強化/大量保有報告書/株主提案/上方修正/資産売却/MBO・TOB
       − 危険信号(継続企業の疑義、直近の増資・希薄化、流動性不足、監理銘柄)
```

- **候補に挙げる条件**:型が2つ以上一致、またはA/B/Cのどれか1つ+カタリストの予兆がある。
- 出力は「銘柄、満たした型、根拠の数字、カタリスト候補、**反対仮説**、危険信号」。連想モデルのレポート形式に合わせる。
- 上位は毎日5〜10銘柄に絞る(量より質)。

### 3.4 損失の限定(C4。銘柄選択と別に先に決める)

| 項目 | 案 |
|---|---|
| 1銘柄の最大損失 | 総資金の0.5〜1%(ぱりてきさす「サイズを落とす」、BNF「1〜2%」、テスタ「先に許容損失」) |
| 損切りの3種 | 価格(直近安値割れ)・時間(想定期間で動かない)・理由(カタリスト消滅、前提崩れ)。**理由を最優先**(かぶ1000) |
| 入る位置 | 片山氏の「損切りしなくて済む位置」=型A/Bの割安の底、またはDの反発点 |
| 一度外れた銘柄 | cis氏の「3回外したら手を引く」を採用 |
| 利確 | 半分利確(かぶ1000)+売却水準をあらかじめ決める(たーちゃん:PER/PBRの目標) |

### 3.5 「勝てる」を確かめる方法(これが最重要)

「有名投資家の手法だから勝てる」とは仮定せず、**過去データで確かめる**。

1. **型ごとに単独で検証**:A・B・C・D それぞれが、同期間のTOPIXや、条件を外した同規模の銘柄群より成績が良いか。
2. **合議(重なり)で上乗せがあるか**:2つ以上一致した銘柄が、1つだけの銘柄より成績が良いか。ここが「投資家の手法を組み合わせる」意味の核心で、**効果がなければこの設計は捨てる**。
3. **偏りの除外**:生存者バイアス(上場廃止銘柄を含める)、先読み(決算の公表日より前の数字を使わない)、流動性(実際に買える出来高・価格で計算)。小型株の検証は、ここを誤ると成績が大幅に水増しされる。
4. **評価指標**:連想モデルと揃える。**的中率**(想定期間内にTOPIX比 +10% 以上)を、同期間のランダムな割安小型株と比べる。サンプルが少ない間は結論を出さない。
5. **投資家の事例の逆引き**:各氏の既知の成功例(業務スーパー、造船など)が、上のスクリーンで**事前に**拾えたか。拾えないなら条件が違う。失敗例・動かなかった例も同数集める(`knowledge/past_cases/` の形式)。

## 4. 決めてほしいこと

1. **採用する型**:A〜D の全部で進めるか、まず A(ネットネット、最も明確)と C(開示×初動)に絞るか。
2. **一次資料の本文**:貼れる分だけ貼ってほしい。特に、かぶ1000氏の売却ルール、たーちゃん氏の売却PER、ぱりてきさす氏のリスク管理記事は、数値の根拠として重要。
3. **資金規模**:流動性の下限(売買代金)を決めるために必要。おおよそで構わない。
4. **ほかに調べたい投資家**:ここに挙げていない人(例:弐億貯男、グロース株の個人投資家など)を足すか。
