### 1.3 共通点と、このリポジトリに足りないもの

- 共通点:**小型株 × 資産に対する割安 × カタリスト待ち × 下値を限定する資金管理**。
- 既存の連想モデルは「ニュース → 連想で買われる銘柄」で、流動性の下限を3億円に置いている(大型・中型寄り)。
- 本モデルは逆に「**まだ誰も動かしていない割安小型株 → 動かすきっかけの予兆**」を探す。時間軸も長い(数週間〜数か月)。連想モデルと役割が重ならない。

## 2. モデルの仮説 【提案】

> **資産価値に対して明確に割安で、かつ6か月以内に再評価のきっかけがありそうな小型株は、下値が限定的で上値が大きい非対称な賭けになる。**

優位性の源泉は、連想モデルと同様に「個人が勝てる場所」に限る。

| 源泉 | 中身 |
|---|---|
| ① 機関が入れない規模 | 時価総額が小さく流動性が薄い銘柄は、大口が買えず調査もされない。個人は小さく入れる |
| ② 開示の読み込み | 決算短信・有報・大量保有報告書・株主提案など、**開示を全部読む**のは人間には重い。LLM が得意 |
| ③ 下値の限定 | ネットネットやPBR割れは、悪くても資産価値が下値の目安になる |

**狙わないもの**:テーマ株の短期の値幅取り(連想モデルの領域)、大型株、信用の高レバレッジ。

## 3. スクリーニング案(3段階) 【提案。数値は初期値で、検証で決める】

### 段階1:機械的な足切り(Python)

| 条件 | 初期値 | 理由 |
|---|---|---|
| 時価総額 | 30億〜500億円 | 小型株の領域。出典の「500億円以下」に合わせる |
| 売買代金(20日平均) | 3,000万円以上 | 小さく入って小さく出られる最低限。連想モデルの3億円より緩い |
| 財務の安全 | 自己資本比率30%以上、有利子負債が現預金の範囲内 | 割安の罠(倒産リスク)を避ける |
| 割安 | 次のどれか:ネットネット比率(下記)が1未満/PBR0.7倍未満/PER10倍前後以下で利益成長が続く | 出典の基準に対応 |
| 除外 | 上場廃止・監理銘柄、継続企業の疑義、直近の大幅な希薄化 | 罠の除外 |

ネットネット比率 = 時価総額 ÷ (流動資産 − 負債総額)。1未満がネットネット。流動資産は評価減(売掛金・棚卸資産に掛け目)を入れた保守版も併記する。

### 段階2:カタリストの予兆(Python+LLM)

「動かすきっかけ」を型に分けて、開示から拾う。

| 型 | 見る開示・データ | 例 |
|---|---|---|
| 株主還元の変化 | 自己株取得、増配、配当方針の改定 | 還元強化の発表 |
| 資本・資産の動き | 政策保有株・不動産の売却、親子上場の解消、MBO・TOB | 資産価値の顕在化 |
| 株主の動き | 大量保有報告書(5%超の新規・増加)、物言う株主、株主提案 | アクティビスト参入 |
| 業績の変化 | 上方修正、黒字転換、受注、四半期の進捗率が高い | 決算の深読み |
| 市場区分・指数 | プライム基準未達、上場維持の改善計画、指数の組入れ | 需給の変化 |
| 事業の変化 | 新規事業、提携、価格改定 | 連想モデルのシナリオと接続 |

- 段階1を通った銘柄ごとに、LLM が直近の開示を読み、カタリスト候補・時期の見込み・**カタリストが来ない理由(反対仮説)**を書く。強化と弱体化の両方を出させる(連想モデルと同じ規律)。
- 「PMV(事業価値)」は、事業の営業利益×妥当倍率+現預金+投資有価証券−負債で概算する。精度は粗くてよく、割安の方向が合っているかだけを見る。

### 段階3:タイミング(Python)

出典の「出来高の急増」「反発パターン」を、機械的に表現する。

- 出来高が20日平均の2倍以上になった日があり、その後の押しで安値を割らない。
- 25日線または直近安値からの反発。
- 需給モデルとは、**ファイル(CSV)の受け渡しで連携**する(既存方針を踏襲)。

## 4. 売買とリスクの案 【提案】

目的は連想モデル同様「探す能力」の評価だが、ポジション管理は出典が最重視する点なので、判断材料として出す。

| 項目 | 案 |
|---|---|
| 1銘柄のリスク | 総資金の**0.5〜1%**を、損切り幅で割って株数を決める(出典の「ポジションを落とす」を数式にした) |
| 同時保有 | 5〜10銘柄。かぶ1000氏の「絞る」方向。ただし小型株は流動性が薄いので上限を設ける |
| 1銘柄の上限 | 売買代金の5%以内(自分の売買で値を動かさない) |
| 損切りの型 | 価格(直近安値割れ)、時間(想定期間で何も起きない)、理由(カタリストが消えた)の3つ。**理由の損切りを最優先** |
| 利確 | カタリストが織り込まれたら段階的に。PMV・資産価値の70〜100%到達を目安 |
| 避ける | 信用の高レバレッジ、流動性の薄すぎる銘柄への集中、希薄化を伴う資金調達の直前 |

## 5. 検証計画(実装前に必須)

「手法が有名だから勝てる」とは仮定しない。過去データで確認してから運用する。

1. **データ**:無料のもの。株価は yfinance、財務は EDINET/決算短信(TDnet は既に収集している)。無料で取れない期間・項目は検証から外し、外したことを記録する。
2. **バイアスの除外**:生存者バイアス(上場廃止銘柄が消える)、先読み(決算発表日より前に数字を使う)、流動性(約定できない価格を使う)。小型株の検証で最も結果が膨らむ点。
3. **段階別の検証**:
   - 段階1だけ(割安の足切り)で、TOPIX に対して超過リターンが出るか。
   - 段階1+カタリスト予兆で、上乗せがあるか。
   - 段階3(タイミング)で、下値リスクが減るか。
4. **合格基準**(連想モデルと揃える):本命に挙げた銘柄の的中率(想定期間内にTOPIXを +10% 上回った割合)が、同期間にランダムに選んだ割安小型株の割合を明確に上回ること。サンプルが少ない間は結論を出さない。
5. **過去事例**:`knowledge/past_cases/` と同様に、成功・失敗・動かなかった事例をまず30件程度作る(失敗を含めること)。

## 7. 決めてほしいこと

1. **方向性**:「割安×カタリスト待ち(数週間〜数か月)」でよいか。それとも、ぱりてきさす氏のデイトレ・短期寄りを強めたいか。
2. **時価総額・流動性の下限**:30億円/売買代金3,000万円で足りるか。資金規模に合わせて調整したい。
3. **既存モデルとの関係**:別モデルとして独立させるか、連想モデルの候補にバリュー評価を足すだけにするか。
4. **一次情報**:両ブログの重要記事の本文を貼れるか(§0 参照)。
